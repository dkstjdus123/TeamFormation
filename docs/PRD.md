# PRD: 팀 프로젝트를 위한 팀 편성 웹 앱

## 1. 목적

학생들이 팀 프로젝트 팀을 스스로 편성합니다. 학생은 팀에 지원하고 팀원은 지원에 투표합니다. 모집이 끝난 뒤 팀에 들어가지 못한 학생은 AI가 배정하고, 앱이 AI의 답을 규칙으로 검사합니다.

## 2. 사용자

| 사용자 | 하는 일 |
|---|---|
| 학생 | 학번과 비밀번호(1234)로 로그인합니다. 팀 목록과 팀원의 주 역할, 보조 역할을 봅니다. 팀에 지원하고, 내 팀에 들어온 지원에 찬성 또는 거부를 누릅니다. |
| 관리자 | 학번 `admin`과 `ADMIN_PASSWORD`로 로그인합니다. 명단 CSV와 팀 수로 처음 상태를 만들고, 모집을 마감하고, AI 배정안을 받아 확정합니다. |

## 3. 규칙

### 3.1 팀

- 팀 수는 관리자가 명단을 올릴 때 정합니다(팀1, 팀2, …).
- 확정한 팀은 모두 2~4명이어야 합니다. 빈 팀은 없어야 합니다.
- 한 팀에 주 역할이 같은 학생이 2명 이상이면 안 됩니다.
- 모든 팀에 기획자와 웹 프로그래머를 맡을 학생이 서로 다른 사람으로 1명씩 있어야 합니다. 주 역할이나 보조 역할로 맡을 수 있습니다.

### 3.2 지원과 투표

| 상황 | 결과 |
|---|---|
| 빈 팀에 지원 | 바로 승인 |
| 팀원이 있는 팀에 지원 | 대기. 투표하는 때의 팀원 모두가 투표함 |
| 모든 팀원이 찬성 | 승인 직전 검사(정원, 주 역할 중복, 필수 포함 역할 자리)를 통과하면 승인, 아니면 거절 |
| 한 명이라도 거부 | 바로 거절 |
| 막힘(지원을 아예 받지 않음) | 팀이 꽉 참, 같은 주 역할의 팀원이 있음, 이미 팀이 있음, 결과를 기다리는 지원이 있음, 모집 마감, 필수 포함 역할 자리가 모자람 |
| 투표 바꾸기 | 할 수 없음 |

필수 포함 역할 자리: 지원자가 들어간 뒤 남는 자리 수가, 그 팀이 아직 채우지 못한 필수 포함 역할 수보다 적으면 막습니다. 한 학생이 기획자와 웹 프로그래머를 둘 다 할 수 있어도 하나로만 셉니다.

### 3.3 마감과 배정

1. 관리자가 모집을 마감하면 대기 중인 지원은 거절되고, 1명뿐인 팀의 학생은 팀에서 빠집니다.
2. AI 배정을 누르면 앱이 먼저 규칙을 지키는 배정이 있는지 모든 경우를 따져 봅니다. 없으면 AI를 부르지 않고 "규칙을 지키는 배정이 없음"과 이유를 보여 줍니다.
3. 있으면 오픈라우터 무료 모델을 1차, 2차, 3차 순서로 부릅니다. 모델마다 120초가 넘거나, 빈 응답, 오류, 검사 실패이면 다음 모델로 넘어갑니다.
4. 검사는 다섯 가지입니다: 팀이 없는 학생이 빠짐없이 배정됨, 한 학생은 한 팀에만 배정됨, 모든 팀이 2~4명, 주 역할 중복 없음, 필수 포함 역할 충족.
5. 3차 모델까지 실패하면 앱이 모든 경우를 따져 찾은 배정을 씁니다.
6. 검사를 통과한 배정안만 관리자에게 보여 주고, 관리자가 확정하면 DB에 저장합니다.

## 4. 화면

- 화면 요소의 Streamlit `key`는 공고 2.7절 표를 그대로 씁니다(`login_student_no`, `result`, `team_1`, `apply_1`, `vote_yes_{학번}` 등).
- 결과 안내(`result`)는 "승인", "대기", "거절", "막힘" 가운데 하나로 시작합니다.
- 학생 화면에서 내 팀 옆에 "(내 팀)"을 붙입니다. 팀이 없으면 "아직 팀이 없음"을 보여 줍니다.
- 이미 팀에 속했거나, 결과를 기다리는 지원이 있거나, 모집이 마감되었으면 지원 단추를 비활성화합니다.
- 이미 투표한 지원에는 단추 대신 "내 투표: 찬성" 또는 "내 투표: 거부"를 보여 줍니다.
- 다른 사람의 변경은 `st.fragment`로 3초마다 바뀐 부분만 다시 그립니다.

## 5. 기술과 제약

- Streamlit Community Cloud 배포, Supabase(PostgreSQL) DB, 테이블 이름은 모두 `tf_`로 시작합니다.
- 키, DB 주소, 관리자 비밀번호는 `.env`(로컬)와 Streamlit Secrets(배포)에만 둡니다. 화면에 출력하지 않습니다.
- 비밀번호는 bcrypt 해시로 저장합니다.
- 오픈라우터 무료 자동 라우터(`openrouter/free`)는 쓰지 않습니다.

## 6. 하지 않는 것

- 구글 로그인, 학생 비밀번호 바꾸기, 팀 이름 바꾸기, 이미 팀에 있는 학생 옮기기.
